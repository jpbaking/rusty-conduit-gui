# src-tauri

Sub-root: Tauri v2 desktop shell, Cargo workspace member `rusty-conduit-gui` (the app binary).

## Purpose
Thin adapter that wires the conduit crates to the Svelte frontend, the system tray, and the OS: IPC commands, the `AppController`, the Manage Window, tray bridging, CLI flags, the one-time upgrade migration, and installer/bundle configuration.

## Ownership
Owns everything under `src-tauri/` except `ui/`, which has its own DOX.md. Inherits all root DOX rules and adds the local rules below. Business logic belongs in `../crates/*`; this crate only adapts it.

## Local Contracts
- `src/commands.rs` holds thin `#[tauri::command]` wrappers only; every IPC operation lives as a plain, window-free method on `AppController` (`src/controller.rs` and `src/controller/`).
- Secrets only flow inward: commands accept `SecretInput` and never return secret values. Every command is `async`.
- The controller owns `config.json`, `known_hosts.json`, `vault.bin`, and the runtime managers.
- `ui/dist` is tracked and read at compile time by `tauri::generate_context!()` (`frontendDist` in `tauri.conf.json`). After changing the frontend, rebuild it (`cd ui && npm run build`) and commit `ui/dist`.
- `gen/` (generated by `tauri-build`) and `binaries/` (staged `conduit-worker` sidecar from `../scripts/stage-worker.py`) are git-ignored build outputs; never edit or commit them.
- Linux uses the `ksni` tray from `../crates/conduit-tray`; Tauri's `tray-icon` feature is enabled only on non-Linux targets. The `conduit_check_tauri_tray` cfg compile-checks the Tauri tray on Linux.
- Closing the Manage Window destroys the webview; tunnels and the tray keep running in Rust.
- Version must match in `Cargo.toml`, `tauri.conf.json`, and `ui/package.json` (checked by `../scripts/validate-release-config.py`).

## Verification
- `cargo test -p rusty-conduit-gui`
- `cargo test -p rusty-conduit-gui --test secret_leak_scan` (CI runs it as its own step)
- Linux only: `RUSTFLAGS="--cfg conduit_check_tauri_tray" cargo check -p rusty-conduit-gui --tests --features tauri/tray-icon`
- Run the app from the repo root: `cargo run -p rusty-conduit-gui` (build `ui` first).

## Feature Map
- **App bootstrap and platform rules** — builder setup, plugins, CLI flags (`--tray`, `--show`, `--safe-rendering`), WebKitGTK mitigations, autostart, single instance. Start: `src/lib.rs`. Files: `src/main.rs`, `src/platform.rs`, `build.rs`, `tauri.conf.json`, `capabilities/default.json`.
- **IPC surface** — command wrappers over the controller. Start: `src/commands.rs`. Files: `src/controller.rs`.
- **Proxy operations** — CRUD, lifecycle, hot reload, tray override, Route Tester, Test Upstream, Profile Library, Start/Stop All, autostart. Start: `src/controller/proxies.rs`.
- **Tunnel operations** — CRUD, lifecycle, safe deletion, host keys, Test Chain. Start: `src/controller/tunnels.rs`.
- **Legacy sessions and editor helpers** — v1 sessions, host profiles, host-key approvals, port-forward presets, port-conflict detection, filter tester, OpenSSH check. Start: `src/controller/sessions.rs`. Files: `src/controller/presets.rs`, `src/controller/parity.rs`.
- **Key vault and secrets** — key vault, write-only secrets, password strength rule, MITM CA upload/list/rename/delete. Start: `src/controller/keys.rs`. Files: `src/controller/password.rs`, `src/controller/mitm_ca.rs`.
- **Backup export/import** — plain and encrypted app backups (format v2; v1 still imports). Start: `src/controller/export.rs`.
- **CLI / AirSwitch import-export and External TOML** — controller side of `.bak` import, `config.toml` import/export, and link mode. Start: `src/controller/import_export.rs`.
- **Upgrade migration from v0.1.0** — moves the old app's data from `io.github.rusty-conduit-ssh-gui`. Start: `src/migration.rs`.
- **Tray integration** — state → menu and menu picks → controller/window; Tauri tray backend for Windows and macOS. Start: `src/tray_bridge.rs`. Files: `src/tray_tauri.rs`, `icons/`.
- **Manage Window lifecycle** — create, show, and destroy the webview. Start: `src/window.rs`.
- **Bundle and installer config** — Tauri bundle settings, icons, NSIS hooks. Start: `tauri.bundle.conf.json`. Files: `windows/nsis-hooks.nsh`, `icons/`.
- **Secret-leak scan** — sentinel-secret scan over exports, logs, errors, data files, and OpenSSH files. Start: `tests/secret_leak_scan.rs`. Files: `src/controller/test_support.rs`.

## Child DOX Index
- ui/ — Svelte 5 + TypeScript frontend (Manage Window) with its own npm build and tests.
